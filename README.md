# NegotAItions / ПереговорИИ localized exact brand assets

This package is based on the selected generated raster logo crop. It intentionally uses PNG assets instead of approximate SVG recreation to preserve the exact visual style, proportions, typography, arrows, figures, and central star.

## Runtime mapping

Russian UI:
- `public/brand/negotaitions-logo-full-ru.png`
- `public/brand/negotaitions-logo-compact-ru.png`
- `public/brand/negotaitions-logo-session-ru.png`

English UI:
- `public/brand/negotaitions-logo-full-en.png`
- `public/brand/negotaitions-logo-compact-en.png`
- `public/brand/negotaitions-logo-session-en.png`

Icon / favicon:
- `public/brand/negotaitions-icon.png`
- `public/favicon.ico`
- `app/icon.png`
- `app/apple-icon.png`

## Usage policy

Do not display both brand names simultaneously in runtime UI.
Use RU assets for Russian UI and EN assets for English UI.
Use PNG assets as source of truth. Do not redraw or approximate as SVG in this iteration.
